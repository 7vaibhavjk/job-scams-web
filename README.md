

  # 🔍 Job Scams Detection Website  

A modern web application built with **React**, **TypeScript**, and **Vite** that helps users identify and avoid fraudulent job postings. The platform provides insights, awareness, and tools to detect scam job advertisements and stay safe in the job market.

---

## 🧩 Features  

- 🛡 **Job Scam Detection Tool**  
  Check suspicious job descriptions and get scam probability indicators.

- 📊 **Data & Insights**  
  Visual representation of job scam trends and stats in Australia.

- ⚡ **Fast Development**  
  Powered by **Vite** for quick builds and lightning-fast HMR.

- 🎨 **Responsive UI**  
  Modern design using **Tailwind CSS** and reusable components.

- 📝 **Awareness Hub**  
  Tips and guidelines for spotting and avoiding job scams.

---

## 📂 Tech Stack  

- **Frontend:** React + TypeScript  
- **Build Tool:** Vite  
- **Styling:** Tailwind CSS (or your styling framework)  
- **Icons:** Lucide React   

---



  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.
