# 🛡️ Protegrad – AI-Powered Job Scam Detection Platform

Protegrad is an AI-driven web platform designed to help **job seekers** identify fraudulent job postings, detect scam URLs, and learn how to protect themselves through interactive education.  

You can access the live version at 🌐 **[https://www.protegrad.app](https://www.protegrad.app)**  

---

## 🚀 Overview

Online employment scams have grown rapidly, targeting vulnerable job seekers. **Protegrad** provides an all-in-one solution combining:  
- Real-time job ad analysis powered by AI  
- Educational awareness through gamified learning  
- AI chatbot for scam recovery support  
- Browser extension for on-the-go URL safety  

---

## 🧠 Core Features

### 🔍 AI Job Ad Analyzer
Paste any job description or website link and get an instant safety report:
- Detects scam-indicative phrases (e.g., “urgent hiring,” “pay upfront”)  
- Provides a clear **Safe / Suspicious** verdict  
- Explains why the ad was flagged  

### 🎮 Education & Awareness
Learn to recognize scam tactics through:
- **Protegrad Racer:** A fast-paced game where users “race” to dodge scams  
- **Flashcard Quiz:** Scenario-based questions to test scam-awareness knowledge  

### 💬 AI Support Center
Interactive chatbot that helps users:
- Understand scam red flags  
- Get personalized post-scam recovery guidance  
- Export reports for formal complaint filing  

### 🧩 Browser Extension
Stay protected while browsing:
- Instant URL legitimacy checks  
- Automatic scam detection on job platforms  
- Lightweight, privacy-first design
